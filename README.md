# معمل الحركة التوافقية

معمل تفاعلي باللغة العربية لشرح الحركة التوافقية البسيطة لطلاب الثانوية العامة. يتضمن محاكاة نابض وكتلة، وتحكمًا في الكتلة وصلابة النابض والسعة وموضع الدورة، وحسابات الحركة والطاقة، وقاموس رموز، وأمثلة محلولة، وتدريبًا تفاعليًا.

## التشغيل

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

المشروع تطبيق ويب مبني باستخدام React وTanStack Start وTailwind CSS، ويُبنى للنشر على Vercel. الوظائف التعليمية الأساسية لا تحتاج إلى مفاتيح API أو قاعدة بيانات.
