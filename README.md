# معمل الحركة التوافقية

معمل تفاعلي باللغة العربية لشرح الحركة التوافقية البسيطة لطلاب الثانوية العامة. يتضمن محاكاة نابض وكتلة، وتحكمًا في الكتلة وصلابة النابض والسعة وموضع الدورة، وحسابات الحركة والطاقة، وقاموس رموز، وأمثلة محلولة، وتدريبًا تفاعليًا.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء والنشر

```bash
npm run build
```

يتم إنشاء نسخة ثابتة للنشر عبر GitHub Pages تلقائيًا عند كل تحديث لفرع `main` باستخدام GitHub Actions.

بعد تفعيل Pages من إعدادات المستودع واختيار **GitHub Actions** كمصدر للنشر، سيكون الموقع على:

https://yousefjoussef72.github.io/harmonic-motion-lab/

المشروع لا يحتاج إلى مفاتيح API أو قاعدة بيانات لتشغيل الوظائف التعليمية.
